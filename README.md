# TrainingGround

> 一个 Unity 3D 技术展厅：仿《王者荣耀》训练营的形式，一个人、一片空地、敌人走过来、旁边一排开关。
> 不追求完整游戏，目标是把 Unity 客户端常用技术各做一个能看、能讲的演示。

**状态**：🚧 施工中（第 0 步：建项目）

## 规划内容

| 场景 | 展示什么 |
|---|---|
| 战斗场景（C# 版 → Lua 版 / HybridCLR 版） | Animator 状态机、混合树、动画帧事件、受击与打击感、对象池、NavMesh 寻路；半透明小窗实时显示正在执行的代码；热更新前后对比 |
| UI 大厅 | 红点、事件系统、循环列表背包、UI 管理器、配置表、签到、存档、图集与 DrawCall 对比、多分辨率适配 |
| 热更新 | HybridCLR（C# 热更）+ xLua（Lua 热更）+ YooAsset 资源更新，服务器在华为云 |

## 怎么打开

- Unity **6000.3.26f1**（Unity 6.3 LTS），渲染管线 URP
- 代码编辑器：JetBrains Rider
